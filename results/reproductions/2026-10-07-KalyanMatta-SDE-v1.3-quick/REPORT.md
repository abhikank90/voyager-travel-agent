## Environment issues hit during this run

- DynamoDB/LocalStack credentials in the environment crashed the personalisation agent. It now falls back to the local store (#19).
- anthropic SDK 1.x removed `temperature` from `messages.create()`. The SDK is now pinned below 1.0 and a lock file was added (#20).
